# ChipWatch — Semiconductor Intelligence

Responsive multi-page website prototype.

## Run locally
From this folder run `python -m http.server 8000` and open `http://localhost:8000`.

## Pages
- `index.html` — landing page with animated silicon atom and access navigation
- `dashboard.html` — intelligence overview dashboard
- `rankings.html` — country standings and search
- `companies.html` — company tracker and filters
- `intelligence.html` — editorial briefings
- `watchlist.html` — locally saved countries and companies
- `about.html` — platform overview

## Interactions
Navigation, country/company search, sector filtering and browser-local watchlist persistence.

## Data
`js/data.js` contains illustrative prototype data, not live market feeds or verified rankings.
